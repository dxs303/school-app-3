# 2ο Δημοτικό Σχολείο Ζευγολατιού — Android εφαρμογή

Η εφαρμογή είναι σκόπιμα απλή: μόλις ανοίξει εμφανίζει αμέσως την επίσημη ιστοσελίδα του σχολείου, χωρίς ενδιάμεσο μενού.

## Λειτουργίες
- Άμεση προβολή της ιστοσελίδας https://blogs.sch.gr/2dimzevgol/
- Πλοήγηση μέσα στις σελίδες του σχολείου και επιστροφή με το πλήκτρο «Πίσω» του κινητού.
- Γραμμή προόδου κατά τη φόρτωση.
- Μήνυμα και κουμπί επαναφόρτωσης σε περίπτωση αποτυχίας σύνδεσης.
- Σύνδεσμοι email ανοίγουν την εφαρμογή ηλεκτρονικού ταχυδρομείου.
- Άλλοι εξωτερικοί ιστότοποι ανοίγουν στον browser του κινητού.

## Δημιουργία APK
Απαιτούνται Android Studio, Android SDK 35 και JDK 17.
1. Αποσυμπιέστε το ZIP.
2. Στο Android Studio επιλέξτε **Open** και ανοίξτε τον φάκελο `2dim-zevgol-android`.
3. Περιμένετε να ολοκληρωθεί το Gradle Sync.
4. Επιλέξτε **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Το APK θα βρίσκεται στο `app/build/outputs/apk/debug/app-debug.apk`.

## Σημαντικό
Το ZIP περιέχει πλήρες έργο Android Studio (πηγαίο κώδικα), όχι έτοιμο APK. Δεν υπήρχε Android SDK στο περιβάλλον δημιουργίας, επομένως δεν έγινε μεταγλώττιση ή δοκιμή σε πραγματική συσκευή. Η αποδοχή μιας απλής εφαρμογής WebView στο Google Play δεν είναι εγγυημένη. Για άμεση διανομή στους γονείς μπορεί να εγκατασταθεί απευθείας το APK.

## Δημιουργία APK μέσω GitHub (χωρίς Android Studio)
1. Δημιουργήστε δωρεάν λογαριασμό στο github.com και ένα νέο αποθετήριο (New repository).
2. Ανεβάστε **τα περιεχόμενα** του φακέλου (όχι τον ίδιο το φάκελο), ώστε τα `app`, `build.gradle.kts`, `.github` κ.λπ. να βρίσκονται στη ρίζα.
3. Πηγαίνετε στην καρτέλα **Actions** → **Build APK** → **Run workflow** (ξεκινά και αυτόματα με το upload).
4. Όταν ολοκληρωθεί (~5 λεπτά), ανοίξτε την εκτέλεση και κατεβάστε το **2dim-zevgol-apk** από την ενότητα Artifacts.
